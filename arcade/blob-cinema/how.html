🎬 BLOB CINEMA — How It Works

The kid's guide to the whole engine. Every step, in plain sight.

📹

1. You press GO LIVE

Your camera or screen starts recording. The video gets chopped into little 2-second pieces called chunks — like slicing a baguette into pieces so it's easy to carry!

press the button…
⬇
🔒

2. Each chunk gets locked

Every piece goes into a magic lockbox (that's encryption!). Each box gets its own key — and the keys are made in a chain: key #2 is made from key #1, key #3 from key #2, like dominoes!

press the button…
⬇
🌊

3. Locked boxes swim to Walrus

The locked boxes get thrown into a giant ocean called Walrus — computers all over the world hold copies. Nobody can open them without the keys! Each box gets a name tag (the blob ID) so we can find it later.

press the button…
⬇
📋

4. We make a treasure map

We write down where every box is — that's the manifest (a treasure map!). The map goes in the ocean too. To watch, you just need the map + the first key — the rest of the keys unfold like magic!

treasure map = { "title": "my stream", "chunks": [ {"n":0, "blob":"abc123…", "key":"K_0"}, {"n":1, "blob":"def456…", "key":"K_1"}, … ] }
⬇
🎒

5. Every map carries a backpack (the TAIL!)

Here's the clever part! Every treasure map has a backpack sewn on — that's the tail. The backpack carries community treasures: game skins, votes, other channels, and notes about when to reblob (that's when we move boxes to fresh spots before they disappear!).

🎒 What's in the backpack?

🎮 game skins & weapons for the arcade
🗳 votes — what should we build next?
📺 other channels to follow
🔄 reblob notes — "move these boxes before they expire!"
🧠 memories — so our robot friends can learn the chain

Why? Because then every video carries a piece of the community. The arcade builds itself, one backpack at a time!

⬇
📺

6. The never-ending TV (the follower!)

The chain follower is a TV that never stops! It reads the treasure map, unlocks each box, and plays the video. When boxes move to new spots (reblob!), it follows the trail to the new map. It just keeps going… forever!

⬇
🔑

7. The 3-part key

To watch someone's stream you need 3 things:

📍 1. LOCATOR — where's the treasure map? (a blob ID)
⚙️ 2. METHOD — how do the locks work? (always the same magic)
🗝️ 3. UNLOCK — the first key! (secret — only in the link)

Give someone all three, and their player can pull your whole chain. No server needed!
