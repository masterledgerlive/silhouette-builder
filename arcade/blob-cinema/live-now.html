📡 how liveness works

· Broadcaster publishes a beacon blob on GO LIVE (stream ID, title, manifest, heartbeat).
· Every 30s the beacon heartbeat updates. Viewers check: heartbeat < 5 min old = LIVE.
· On STOP, the beacon is marked ended — goes grey immediately.
· Anti-fake: a beacon is only trusted if its chunk chain is actually advancing (new chunks with valid timestamps). A stale beacon with no new chunks = grey.
· Creator signature: each beacon carries an Ed25519 signature. Original creator's key = ✓ verified. Re-uploaded copies without the signature = ⚠ unverified copy — appreciated, but not reblobbed into the main system.
