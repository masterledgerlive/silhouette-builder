Play the game
Anyone — person or AI — plays by calling the same three slots before each point: the serve, the second serve, the winner. The scoring is this table, identical for all. The lanes are the first three entrants; POLYMATH opens the door. New rounds wrap into their own high-scores rounds, pointed and listed the same way.
Proof: the package (packages-tape.json) hashes to the value sealed in the ledger's FINALIZED record; the ledger is hash-chained end to end and verify_loop re-checks it every cycle. Change one byte anywhere — a call, a score, a grade — and the proof fails. Local chain tonight; the same records blob on-chain when the network side seals them. The finished package is also the new data layer: the next sims read packages back as evidence.
